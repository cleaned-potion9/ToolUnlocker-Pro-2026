## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is designed as a local utility and scans show no tool. However, anticomponent software may flag patching tools; you may need to add an exception.

### Which versions of Windows are supported?

OmniPatch officially supports Windows 10 (64-bit) and Windows 11.

### How often is OmniPatch updated?

Updates are released within a week after major updates to any supported AI application to maintain compatibility.

### Does this work with the latest version of ChatGPT Desktop?

Yes, our team actively tests and patches the most recent releases of all supported applications.

### Can I use this on multiple computers?

The patch is applied per-device. You can run OmniPatch on any number of computers you own.

### Will this affect my existing account or data in the AI apps?

No, OmniPatch only modifies local application files to unlock features. Your account data and history remain intact.

### What if an update breaks the patch?

We recommend pausing auto-updates for target apps until an OmniPatch update is available. Check our Releases page for news.

### Is there support for macOS or Linux?

Currently, OmniPatch is a Windows-only utility. We have no plans for other platforms at this time.
